====================================================================
  ม็อดภาษาไทย Delta Force: Black Hawk Down + Team Sabre
====================================================================

ฟีเจอร์ในม็อดนี้:
- แปลภาษาไทยครบทั้งตัวเกมหลักและภาคเสริม Team Sabre (เมนู, ภารกิจ, อาวุธ, HUD)
- แก้ระบบตัดคำและจัดวางข้อความภาษาไทยเต็มกล่อง (หน้าสรุปภารกิจ, จัดอาวุธ)
- รองรับการพิมพ์ภาษาไทยในช่องแชทระหว่างเล่น
- แก้ปัญหาแครช/จอดำบน Windows ยุคใหม่ (รวมตัวแก้ IME และ dgVoodoo2 D3D8)

--------------------------------------------------------------------
วิธีที่ 1: ติดตั้งอัตโนมัติ (แนะนำ)
--------------------------------------------------------------------
1. ปิดตัวเกม Delta Force: Black Hawk Down ให้เรียบร้อยก่อน
2. ดับเบิลคลิกไฟล์ Install-ThaiMod.bat
   (หากตัวเกมอยู่ใน Program Files ให้คลิกขวาแล้วเลือก Run as administrator)
3. กด Y เพื่อยืนยันโฟลเดอร์เกม (หรือวาง/ลากโฟลเดอร์เกมมาใส่ถ้าโปรแกรมหาไม่เจอ)
   * สคริปต์จะสำรองไฟล์ต้นฉบับไว้ในโฟลเดอร์ Backup_Original ให้อัตโนมัติ
4. เสร็จแล้วเข้าเล่นเกมผ่าน dfbhd.exe หรือชอร์ตคัตเดิมได้ทันที!

--------------------------------------------------------------------
วิธีที่ 2: ติดตั้งแบบก๊อปปี้วางด้วยตัวเอง (Manual)
--------------------------------------------------------------------
1. (แนะนำ) สำรองไฟล์เดิมในโฟลเดอร์เกมไว้ก่อน ได้แก่:
   - dfbhd.exe
   - d3d8.dll (ถ้ามี)
   - localres.pff
   - EXP1.pff
   - resource.pff
   - dgVoodoo.conf (ถ้ามี)
2. เปิดเข้าไปในโฟลเดอร์ ModFiles แล้วก๊อปปี้ไฟล์และโฟลเดอร์ทั้งหมดข้างใน:
   - dfbhd.exe
   - d3d8.dll
   - thai_glyph_map.bin
   - localres.pff
   - EXP1.pff
   - resource.pff
   - dgVoodoo.conf
   - wrappers\
   นำไปวางทับในโฟลเดอร์ที่ติดตั้งเกม (ที่มีไฟล์ dfbhd.exe อยู่)
3. เข้าเล่นเกมผ่าน dfbhd.exe ได้เลย

--------------------------------------------------------------------
วิธีถอนการติดตั้ง (กลับเป็นภาษาอังกฤษเดิม)
--------------------------------------------------------------------
- ดับเบิลคลิกไฟล์ Uninstall-ThaiMod.bat (สำหรับผู้ที่ติดตั้งด้วยวิธีที่ 1)
  หรือนำไฟล์จากโฟลเดอร์ Backup_Original กลับไปวางทับที่เดิม

--------------------------------------------------------------------
หมายเหตุ / การแก้ปัญหาเบื้องต้น
--------------------------------------------------------------------
- ม็อดนี้สร้างและทดสอบกับตัวเกมเวอร์ชัน GOG (v1.5.0.5) + Team Sabre
- หากเข้าเกมแล้วจอดำหรือมีปัญหาภาพ ลองเปิดดูไฟล์ thai_runtime.log ในโฟลเดอร์เกม
- ต้องมีครบทั้ง d3d8.dll, thai_glyph_map.bin และโฟลเดอร์ wrappers\dgVoodoo\D3D8.dll
  (ห้ามลบโฟลเดอร์ wrappers ออกเพราะ d3d8.dll เรียกใช้งานต่อจากโฟลเดอร์นี้)
